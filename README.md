# Тренажёр по операционным системам

Выбери одну из двух тем, ответь на три вопроса и получи результат с пояснениями к ошибкам. Django показывает страницы и проверяет ответы, PostgreSQL хранит вопросы, а Valkey кеширует список тем на пять минут.

## Запуск

Запустите Docker Desktop и выполните из папки проекта:

```bash
docker compose up --build -d
```

При старте Django применяет миграции и загружает демонстрационные вопросы. Откройте http://localhost:8000.

## Проверка

- Во время теста оставьте один вопрос пустым. Форма должна попросить ответить на него и сохранить уже выбранные варианты.
- Дайте два правильных ответа и один неправильный. Ожидаемый результат — «2 из 3» и пояснение к ошибке.
- Откройте главную страницу и обновите её. Строка «Список тем получен из: Valkey» показывает, что список прочитан из кеша.
- Для запуска автоматических тестов выполните `docker compose exec web python manage.py test`.

## Структура проекта

- `spec.md`, `plan.md`, `tasks.md` — требования, план и задачи.
- `AGENTS.md`, `.opencode/skills/add-exam-question/SKILL.md` — правила для агента и инструкция по добавлению вопросов.
- `opencode.json` — конфигурация MCP-сервера Context7, который использовался для поиска документации Django.
- `exam_trainer/` — настройки Django, `trainer/` — модели, миграции, страницы, тесты и команда загрузки вопросов.
- `docker-compose.yml` — конфигурация Django, PostgreSQL и Valkey.

Для остановки выполните `docker compose down`.
