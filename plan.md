# План реализации

1. Docker Compose запускает три сервиса: Django, PostgreSQL и Valkey.
   Сайт доступен на localhost:8000. Данные PostgreSQL сохраняются в томе Docker.
2. В PostgreSQL храним темы, вопросы и варианты ответа. Каждый вопрос
   относится к одной теме и имеет один правильный вариант и пояснение.
   Добавляем две темы и по три вопроса для демонстрации.
3. Django показывает список тем и форму теста. При отправке он проверяет
   ответы на сервере. Если ответ пропущен, форма сохраняет выбранные варианты
   и показывает сообщение рядом с пропущенным вопросом.
4. Django кеширует список тем в Valkey на 5 минут. При пустом кеше он
   читает темы из PostgreSQL и записывает их в Valkey. Повторный запрос
   до истечения этого срока читает список из кеша.
5. В README описываем запуск, загрузку вопросов и проверку теста и кеша.
