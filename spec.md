# Тренажёр для подготовки к экзамену по операционным системам

## Сценарий пользователя

1. На главной странице студент выбирает одну из двух тем:
   «Процессы и потоки» или «Управление памятью».
2. В каждой теме три вопроса. У каждого вопроса один правильный ответ.
3. После отправки теста студент видит результат, например «2 из 3»,
   и правильный ответ с пояснением к каждой ошибке.
4. Если студент пропустил вопрос, сайт просит ответить на него
   и сохраняет уже выбранные варианты в форме.
5. После просмотра результата можно пройти тест заново
   или вернуться к списку тем. Регистрация не требуется.

## Технические требования

- Django показывает страницы и проверяет ответы на сервере.
- PostgreSQL хранит темы, вопросы, варианты и пояснения.
- Valkey кеширует список тем. При пустом кеше Django читает список
  из PostgreSQL, а при следующем запросе берёт его из Valkey.
- Docker Compose запускает Django, PostgreSQL и Valkey.
- В репозитории есть README с запуском и способом проверить кеш.

## Проверка результата

- Два верных ответа и один неверный дают «2 из 3» и одно пояснение.
- Пропущенный вопрос подсвечивается, выбранные ответы остаются в форме.
- При первом открытии главной список тем попадает в Valkey,
  при повторном открытии Django читает его из кеша.
