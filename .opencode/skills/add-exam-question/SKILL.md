# Добавление экзаменационных вопросов

1. Возьми тему из spec.md и сформулируй один понятный вопрос.
2. Подготовь четыре варианта ответа. Ровно один должен быть правильным.
3. Напиши короткое пояснение, почему этот вариант правильный.
4. Добавь вопрос в демонстрационные данные проекта.
5. Проверь, что повторная загрузка данных не создаёт дубликаты,
   а после неверного ответа сайт показывает правильный вариант и пояснение.
